# OpenID4VCI Protobuf Codec

`openid4vci-proto-codec` provides bounded conversions between the canonical
ReallyMe OpenID4VCI protobuf messages and the validated Rust domain types.

It enforces explicit size, recursion, and representation limits at the protobuf
and ProtoJSON boundaries.

See the [ReallyMe OpenID4VCI repository](https://github.com/reallyme/openid4vci)
for architecture, security, and conformance documentation.
