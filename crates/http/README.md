# OpenID4VCI HTTP

`openid4vci-http` provides feature-gated HTTP framing adapters for the ReallyMe
OpenID4VCI issuer and holder boundaries.

The crate does not own deployment policy, persistence, trust-anchor selection,
or end-user authorization. Applications compose those capabilities explicitly.

See the [ReallyMe OpenID4VCI repository](https://github.com/reallyme/openid4vci)
for architecture, security, and conformance documentation.
